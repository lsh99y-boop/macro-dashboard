# 매크로 밸류·사이클 대시보드

김영익 소장이 쓰는 두 지표 — **코스피 시총 ÷ M2 비율**(통화량 대비 밸류에이션 과열)과
**선행지수 순환변동치**(경기 사이클) — 를 공개 데이터로 재현하고, 한 단계 더 가공해
신호(signal)로 만든 도구입니다. 파동/피보나치 단타 레이어에 얹는 **중장기 배경 필터**.

## 만들어지는 지표
1. **시총/M2 비율 + Z스코어** — 비율을 그리되 "장기평균 대비 몇 σ 과열"인지 신호등(🔴🟡🟢)으로.
   M2가 꾸준히 커지는 편향을 보정한 **추세보정 Z(5년 롤링)** 도 함께 제공.
2. **선행지수 순환변동치 4국면** — 100 기준 위/아래 × 3개월 방향으로 확장·둔화·수축·회복 자동 라벨링.
   '3개월 연속 하락 = 정점 유력' 규칙으로 정점/저점 잠정 판정.
3. **과열 × 사이클 2축 매트릭스** — 1번(X축)과 2번(Y축)을 합쳐 지금 어느 사분면에 있는지.

## 데이터 출처 (모두 무료·공개)
| 지표 | 출처 | 코드 | 주기/시차 |
|---|---|---|---|
| M2(광의통화, 평잔) | 한국은행 ECOS | `161Y006 / BBHA00` | 월간, 1~2개월 시차 |
| 선행지수 순환변동치 | 한국은행 ECOS | `901Y067 / I16E` | 월간, 사후개정 |
| 코스피 시가총액 | KRX / [marcap](https://github.com/FinanceData/marcap) | 일별 전종목 합산→월말 | 거래일 기준 최신 |

> KOSIS 키는 필요 없습니다 — 선행지수 순환변동치를 한국은행 ECOS에서 받습니다.

## 실행
```bash
# 1) 가상환경 + 패키지 (최초 1회)
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2) 대시보드 생성 → output\macro_dashboard.html
.venv\Scripts\python.exe build_dashboard.py
```
ECOS 키는 코드에 넣지 않습니다. 로컬은 프로젝트 폴더에 `.ecos_key` 파일(키 한 줄),
GitHub Actions는 저장소 Secret `ECOS_KEY` 로 주입합니다. 폰 배포는 [DEPLOY.md](DEPLOY.md) 참고.

## 파일
- `config.py` — ECOS 키·통계코드·경로·임계치
- `macro_fetch.py` — 데이터 수집 (ECOS + marcap 캐시)
- `macro_indicators.py` — 지표 계산 (3종)
- `build_dashboard.py` — 수집→계산→HTML 리포트

## 유의사항
- M2·순환변동치는 **확정값이 아닌 월간·사후개정** 지표입니다. 최근 월은 잠정.
- 비율의 장기평균선은 M2 증가로 **우상향**합니다 → "평균(57%)까지 회귀" 단정은 위험. 추세보정 Z 병행.
- 정점/저점은 **사후에만 확정**됩니다. 규칙 기반 판정은 참고용.
- 월간·중장기 국면용 — **단타 신호 아님**.
